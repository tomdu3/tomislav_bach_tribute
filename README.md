# Tomislav's Bach Tribute Web Page

A tribute page dedicated to the legendary composer Johann Sebastian Bach.

This project showcases his life, works, and enduring legacy through a clean and responsive web design.

It is built using HTML and CSS, incorporating Google Fonts for enhanced typography.

The favicon is generated by [Favicon.io](https://favicon.io/) app. This project was originally developed on [Codepen](https://codepen.io/tomdu3/pen/yyOzpmr?editors=1100).
